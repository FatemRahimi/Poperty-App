# V1.2 Phase 9.2 — Production private evidence deployment

This phase does **not** invent a cloud provider, scanner, or credentials.

## Deployment audit (repository evidence)

| Area | Evidence |
| --- | --- |
| Docker | `Dockerfile` serves the **client** via nginx. It is not the API host. |
| Compose | `docker-compose.yml` is **development-only** (`NODE_ENV=development`). No private-evidence volume. No ClamAV service. |
| CI/CD | No `.github` workflows, Procfile, render/railway/fly/heroku/app.yaml. |
| Cloud SDKs | `server/package.json` has no AWS, Azure, GCP, Cloudflare R2, or MinIO client. `pg-cloudflare` is a `pg` optional dependency, not R2. |
| Object store | `IMPLEMENTED_PRODUCTION_BACKENDS = []`. |
| Scanner | No ClamAV / hosting scanner config. `IMPLEMENTED_SCANNERS = []`. |
| Backups | Local `pg_dump` scripts exist for a developer database. No object-storage backup. No coordinated restore. |
| Public uploads | `express.static('/uploads')` remains marketing photos only. Private evidence is not mounted. |

Classification: **`NO_PRODUCTION_PROVIDER_EVIDENCE`**.

## Adapter boundary

Consumers still use `put` / `read` / `exists` / `delete` / `stat`.

- Development: `LOCAL_PRIVATE` / `DEVELOPMENT_LOCAL` / capability `DEGRADED`.
- Production: ingest stays **fail-closed** until an implemented backend **and** an implemented scanner exist.
- Unknown `PRIVATE_EVIDENCE_PROVIDER` or `PRIVATE_EVIDENCE_PRODUCTION_BACKEND` names fail closed.
- Production never falls back to local disk or `/uploads`.
- Signed object URLs are **not** implemented. Retrieval stays through authorised application access.

## Encryption at rest

Status: **`NOT_VERIFIED`**.

No provider configuration in this repository supports a verification claim. Do not implement custom cryptography.

## Durability

Local disk is not production-durable. Compose bind-mounts are development ephemeral from a custody standpoint. Production objects must not silently use `DEVELOPMENT_LOCAL`.

## Malware

Status: **`NO_SCANNER_AVAILABLE`**.

Magic-byte checks are not a scanner. `CLEAN` requires a real implemented scan result with `verifiedClean=true`.

Production ingest remains fail-closed without a real scanner.

Pipeline when a real scanner later exists:

`RECEIVE → QUARANTINE → SCAN → CLEAN → AVAILABLE`

Rejected / error / unavailable / pending files are not downloadable and are not Legal-available evidence.

## Backup / recovery

| Store | Status |
| --- | --- |
| DATABASE | `NOT_VERIFIED` (local `pg_dump` scripts are not production custody) |
| OBJECT STORAGE | `NOT_VERIFIED` (no production object store) |
| Coordinated | `NOT_VERIFIED` |

Minimum operational recovery requirement (external to application code):

1. Restore the database rows in `evidence_documents` / `evidence_document_subjects`.
2. Restore the corresponding private object bytes for each `storage_key`.
3. Re-run `npm run audit:private-evidence`.
4. Treat `DELETE_FAILED`, missing objects, integrity mismatches, and quarantined rows as unread/unavailable until resolved.
5. Do **not** invent bytes, hashes, or Legal conclusions to fill gaps.

A row without bytes, or bytes without a row, is not recoverability.

## External blockers required before production ingest

1. A real private object backend present in **this** deployment (SDK + credentials + private bucket/container, not public).
2. Encryption-at-rest evidence from that provider or host (no app-level crypto).
3. Coordinated backup of DB rows **and** object bytes, with a restore drill.
4. A real malware scanner in the same environment, wired through the scanner adapter.
5. An authorised user-supplied safe test document for the operational smoke (do not fabricate legal evidence).

## Configuration (server-side only)

| Variable | Purpose |
| --- | --- |
| `PRIVATE_EVIDENCE_PROVIDER` | `local` or `production`. Unknown names fail closed. |
| `PRIVATE_EVIDENCE_PRODUCTION_BACKEND` | Must match an **implemented** backend. None are implemented. |
| `PRIVATE_EVIDENCE_SCANNER` | Must match an **implemented** scanner. None are implemented. |
| `PRIVATE_EVIDENCE_SCANNER_TIMEOUT_MS` | Scanner timeout (fail-closed). |
| `PRIVATE_EVIDENCE_ROOT` | Development local root only. Must not be `/uploads`. |
| `PRIVATE_EVIDENCE_SMOKE_DOCUMENT` | Optional path to an authorised user-supplied smoke file. |

Secrets must not appear in git, client, snapshots, or logs.
