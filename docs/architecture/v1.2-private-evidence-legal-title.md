# V1.2 Phase 9 — Private evidence + Legal Title activation

LEGAL_TITLE now consumes owner-private uploaded documents. Upload proves `FILE_RECEIVED`, not authenticity, and never a legal conclusion.

- Storage: private storage interface (`put`/`read`/`exists`/`delete`). Local root `server/private-evidence/` is development-only (not `/uploads`, not `express.static`). See `v1.2-private-evidence-hardening.md`.
- Tables: `evidence_documents`, `evidence_document_subjects`
- Routes: `/api/ai/intelligence/legal-evidence`
- Live envelope: `report.legalTitleDomain` (owner-scoped documents only)
- Extraction: `NOT_EXTRACTED` / not attempted
- Provider cost: none
